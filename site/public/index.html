常见问题Questions

考试里可以用吗？Can I use it in the exam?

VCAA 的 Methods 和 Specialist Exam 2 允许带经批准的 CAS 计算器，而且不要求清空内存，所以计算器里的文档可以带进考场。规定每年可能有变化，请以 VCAA 和学校的最新通知为准。 VCAA allows an approved CAS calculator in Methods and Specialist Exam 2 and does not require its memory to be cleared, so documents on it come with you. Rules can change: check the latest VCAA and school notices.

支持哪些计算器？Which calculators does it run on?

为 TI-Nspire CX II CAS 设计，也可以在电脑上的 TI-Nspire CX CAS Student Software 里打开。它需要 CAS，所以不带 CAS 的型号不能用。 It is made for the TI-Nspire CX II CAS and also opens in TI-Nspire CX CAS Student Software on a computer. It needs a CAS, so non-CAS models cannot run it.

网页上的演示和计算器上一样吗？Is the web demo the same as on the calculator?

界面和操作是同一份程序，完全一样。区别只在计算：网页用的是简化引擎，计算器上用的是 TI 真正的 CAS，精确答案的写法可能略有不同。 The screens and keys come from the same program. Only the maths differs: the web uses a simplified engine, the calculator uses the real TI CAS, so exact answers may be laid out slightly differently.

换新版本，旧的题目还在吗？Do I keep my saved problems when I update?

做过的题保存在文档里。用新文件替换旧文件后，历史会清空；想保留的话，可以先把旧文件改名留着。 Problems are saved inside the document, so replacing the file starts a fresh history. Rename the old file first if you want to keep it.

反馈里的邮箱会怎么用？What happens to my email?

只保存你在表里填的内容，只用来回复你；勾选了通知的话，有新版本时会发一封邮件。不会公开，也不会给别人。 We keep only what you type in the form, use it only to reply, and, if you ticked it, to tell you about new versions. It is never shown or shared.
