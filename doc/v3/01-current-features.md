# 现有功能总结（2.4）

> 依据：读代码整理（`apps/vce/`、`views/`、`ui/`、`site/`、测试和构建脚本），版本 2.4。用于 3.0 搬迁时逐条核对，不丢功能。

## 1. 产品形态

| 产物 | 内容 |
|---|---|
| `vce.tns` | VCE 数学工具箱，只有英文（约 155 KB） |
| `vce_zh.tns` | 同一个工具箱，中英双语（约 173 KB；步骤保持英文，因为考试用英文） |
| `rpn.tns` | 原来的 rpnspire RPN 计算器；在它的工具列表里可以打开工具箱，答案可以“送到 RPN 栈” |
| 网站 | Cloudflare Worker：下载、教程（在浏览器里用真实脚本演示）、更新说明、反馈表（D1 数据库）、用 USB 直接把文档发送到 CX II |

## 2. 首页和通用功能

- **首页**：10 个主题，按数字键 1–9、0 直接打开；分组（函数、微积分、力学、概率、向量）；每个主题标 MM / SM；“最近”显示最近 3 个题目；“更多”里有历史记录、设置、帮助与按键、自检。
- **题目页**：上面是输入框（可以是选项），下面依次是提示、图像、答案（绿色）、步骤。
  - 输入框可以带漂亮的数学预览（含 `/ ^ √` 等时）。
  - 自动补全括号，跳过已有的右括号。
  - 输入时可插入文档里的函数（f11 等）和常用符号。
  - 空题目有“试一个例子”，填入例题后跳到答案。
- **答案**：
  - enter 或 ◀▶ 在精确值和小数之间切换；d / e 把整页改为小数 / 精确。
  - 公式型答案（运动学）按 W 打开只属于它的步骤。
  - 答案可以显示定义域。
  - ctrl+C 复制当前显示的样子；可以存到变量；在 rpnspire 里可以送到 RPN 栈。
- **历史记录**：
  - 最多 60 个题目，随文档保存。
  - 可以加标签（如 `2023 E2 Q5b`），按标题、输入和标签搜索。
  - 上一题 / 下一题、复制题目、清空输入、删除。
- **设置**：
  - 小数位数 2–6；答案默认精确或小数；字号小 / 中 / 大；颜色（柔和米色或纯白）。
  - 语言（只在中文版里出现）。
- **无障碍设计**：每屏选择少；选中行有蓝条；输入框有边框；提示栏写出下一个键；颜色柔和；句子型答案会自动换行。
- **自检**：64 个已知题目在本机 CAS 上运行，报告通过与否。
- **离开输入框再算（2.4）**：作图、参数、变换、面积体积、微分方程这几个主题，在输入框之间移动时不计算，离开输入框才算；编辑时图像显示占位。

## 3. 各主题（18 个解题器）

### 函数

| 主题 | 输入 | 能求出的东西 |
|---|---|---|
| **函数图像与特征**（graph） | f(x)；x 范围；y 范围（可选，只填一边时另一边自动）；六个显示选项（渐近线、驻点、拐点、截距、间断、标签） | f′、f″；竖直 / 水平 / 斜 / 曲线渐近线；极大、极小、驻点拐点；拐点；x、y 截距；空心点、跳跃、端点；尖点（不可导点）；带标注的图 |
| **求未知常数**（params） | 含字母的 f(x)；最多 6 个条件（`f(1)=3`、`f'(2)=0`、`(2,5)`、`tp(1,2)`、`tangent y=2x+1 at x=1`、`asymptote x=2`、任意方程如 `integral(f(x),x,0,1)=2`） | 每个条件的方程；联立解（多组解全部列出）；代回后的 f(x)；逐条验证；带点、切线、渐近线的图；条件不够时提示 |
| **图像变换**（transform） | f(x)；像（用 f 写，如 `2f(3x-6)+4`，或直接写规则，如 `3(x-1)^2+2`）；可选的一个点 | A、n、b、c；按 VCE 顺序写出的变换；映射 (x, y) → (…) 及其逆；点的像；两条曲线的图 |
| **含参数的联立方程**（simul） | 2 或 3 个方程，可以有一个参数 k | 唯一解的条件；解；无解 / 无穷多解时 k 的值；通解（λ、μ） |

### 微积分

| 主题 | 输入 | 能求出的东西 |
|---|---|---|
| **面积、体积、弧长、表面积**（revolution） | 曲线类型（y=f(x)、x=g(y)、参数式）；可选的第二条曲线；上下限（x 值或 y 值，可以含字母 a）；旋转轴；“已知”（`V=16pi`、`A=4`） | 面积（在零点处分段）和有符号积分；圆盘 / 垫圈体积；绕另一条轴时用反函数或柱壳；弧长、表面积；带阴影的图；含字母时给出关于字母的式子，或由已知量求字母 |
| **微分方程模型**（demodels） | 模型：增长 / 衰减、牛顿冷却、逻辑斯蒂、混合（水箱）、一般 dy/dx、相关变化率；初值、第二个数据点、半衰期 / 倍增时间；“求”（`t=10`、`N=200`） | 微分方程和解；k；某时刻的值或达到某值的时间；倍增时间 / 半衰期；极限值；逻辑斯蒂的最快增长点和最大速率；混合问题的量和浓度；deSolve 结果、欧拉表、斜率场；相关变化率的链式法则 |

### 力学

| 主题 | 输入 | 能求出的东西 |
|---|---|---|
| **匀加速（SUVAT）**（suvat） | s、u、v、a、t 中任意三个 | 其余两个（多解全部列出，舍去 t<0）；给多于三个时检查是否一致 |
| **变加速运动学**（kinematics） | 给定类型 a(t)、a(v)、a(x)、v(t)、v(x)、v²(x)、x(t)；表达式；t0、x0、v0；另一条件（如 `a=-3.5 when v=7`）；t1–t2 区间；“求公式”（如 v(x)）；“求值”（x、v、a、t）和“当” | 自动选对的关系式（dv/dt、v dv/dx、dt/dv=1/a…）；全部可求的公式（x(t)、v(t)、t(v)、x(v)…），带定义域；终端速度；某时刻 / 某位置 / 某速度时的量；区间内的位移、路程、平均速度、平均速率（在转向点处分段）；未知常数；条件不够时告诉你要补哪个已知值；单个公式的步骤（W） |

### 概率与统计（一个主题，先选题型）

| 题型 | 能求出的东西 |
|---|---|
| 正态分布 | 概率（含条件概率、标准化的 Z 形式）；由概率求 x（invNorm）；由概率求未知界 k、未知 μ 或 σ；方差 ↔ 标准差 |
| 正态：由两个条件求 μ、σ | μ、σ、方差 |
| 二项分布 | 概率（含 ≠、条件概率）；均值、方差、标准差；由均值 / 方差求 n、p；最小的 n；由概率求 p |
| 离散随机变量 | 未知概率 k（一个或两个，两个时用 E(X)）；均值、E(X²)、方差、标准差、中位数、众数、概率 |
| 概率密度函数 | 分段 pdf；k；均值、方差、标准差、中位数、众数、百分位数；概率 |
| 样本比例与置信区间 | p̂ 的分布、概率（二项精确值和正态近似）；置信区间、误差范围、z；由区间求置信水平；所需样本量 |
| 样本均值与置信区间 | 同上（均值版） |
| 随机变量的线性组合 | aX+bY 的均值、方差、标准差；事件可以定义 W（如 `X1+X2>2Y`）；正态时的概率 |
| 假设检验（均值） | 标准误、z、p 值、结论；临界值；第一类 / 第二类错误、检验效能 |

### 向量

| 主题 | 输入 | 能求出的东西 |
|---|---|---|
| **向量夹角**（vectors） | 两个向量（`2i-j+3k`、`(2,-1,3)`、`<…>`、`[…]`、列向量），或三个点求 ∠ABC；0–180° 或锐角；度或弧度；向量里可以有一个字母 m，给出角度时求 m | 点积、模长、cos θ、θ（精确和小数）、锐角；由角度求 m（全部解） |

## 4. 图像

- **迷你图**：在题目页里，enter 打开全屏。
  - 显示网格、坐标轴、刻度；红色虚线渐近线（落在坐标轴上时画在轴的两侧）；带标签的特征点（标签自动避开曲线和其他点）。
  - 区域阴影；斜率场；竖线 / 横线标记。
- **全屏**：
  - ◀▶ 沿曲线追踪；▲▼ 在特征点之间跳；tab 换曲线；+ / − 缩放。
  - 8 4 6 2 平移；5 或 0 复位；l 标签、a 渐近线开关；点击定位。
- **性能**：
  - 同一窗口只采样一次，之后录制回放。
  - 迷你图裁剪在表格内。
  - 编辑输入框时显示占位，离开再画（2.4）。

### 重复代码（搬迁时合并）

- **正态分布函数**：`ncdf` 在 normal 和 hyptest 里各写了一遍，sampling、lincomb、proportion 里又各内联了一次。
- **置信区间**：proportion 和 sampling 重复了同样的几段：置信水平转换、由水平求 z、由区间求中心和误差、由区间求水平、样本量取整。
- **离散和 pdf**：discrete 和 pdf 重复了“由有效性条件求 k”和“两个未知数用 E(X)”两段。
- **条件概率**：交集的写法出现了三次（normal、binomial、pdf）。
- **求未知常数**：有六套实现（params、kinematics、revolution、vectors、discrete、pdf）。
- **手写解析**：多组解的解析（params、kinematics）、括号匹配和点的解析（params、transform）、去掉等号左边（params、transform）。
- **辅助函数**：代入用的 `at()` 有三种不同签名。
- **图像窗口**：每个解题器各自计算（params、transform、revolution、demodels）。
- **未使用的函数**：`util.count`、`util.rel_text`。

### 自检没有覆盖的路径

- 运动学：v²(x)
- 面积体积：类型 x=g(y)
- 二项分布：求 p
- 离散随机变量：两个未知数
- pdf：百分位数 q
- 假设检验：双侧
- 微分方程：给半衰期或倍增时间
