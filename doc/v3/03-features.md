## A. 选中答案，按 enter 展开它的步骤（P1，所有主题）

### A.1 现在的问题

一次求解会给出很多答案。例如函数图像会给出导数、渐近线、驻点、拐点、截距；运动学会给出一组公式。现在步骤是答案下面的一整串，要自己找哪几行属于哪个答案。2.2 加的 W 键只对“公式型”答案有效（实际上只有运动学：只有运动学和向量给步骤打了 `R:tag`），而且会跳到另一个屏幕。

### A.2 交互

```
┌ Graph · f(x)=(x²−3)/(x−2) ─────────────── 1/3 ┐
│ ▸ Asymptotes (2)                              │  ← 分组标题：enter 折叠/展开
│ ▾ Turning points (2)                          │
│ ▌ Local max  (1, 2)                     ▾     │  ← 选中答案，按 enter 展开
│   │ uses  f′(x) = (x²−4x+3)/(x−2)²     ▸      │  ← 依赖的结论：折叠成一行，enter 展开
│   │ 1. f′(x) = 0 ⇒ x² − 4x + 3 = 0            │
│   │ 2. x = 1 or x = 3                         │
│   │ 3. f″(1) = −2 < 0 ⇒ local maximum         │
│   │ 4. f(1) = 2                               │
│   Local min  (3, 6)                     ▸     │
│ ▸ Intercepts (3)                              │
└ enter: hide working · ◀▶ exact/decimal ───────┘
```

| 位置 | 按键 | 动作 |
|---|---|---|
| 答案行 | enter | 在它下面展开它自己的步骤；再按一次收起 |
| 答案行 | ◀ ▶ | 精确 ⇄ 小数。答案太长时先横向滚动，滚到头再切换 |
| 步骤里的 “uses …” 行 | enter | 原地展开那个依赖结论的步骤（可以一层层展开） |
| 步骤行 | ▲▼ | 正常移动；步骤行可以选中、复制 |
| 分组标题 | enter | 折叠/展开这一组 |
| 任何地方 | esc | 先收起当前展开的步骤，再按才是返回 |
| menu | “显示全部步骤” | 旧的整页步骤（按依赖顺序），给想从头读的人 |

- 展开状态和精确/小数选择按答案的 id 保存在题目里，下次打开还是一样。
- 一次只自动展开一个答案：展开新的答案时，上一个自动收起。设置里可以改成“允许同时展开多个”。
- 分组默认展开；一组超过 4 个时默认折叠，只显示数量。
- 主答案和次要答案：例如 f′、f″ 在作图主题里是次要的，放在“更多”分组里。主题用 `primary` 标记。
- 精确/小数原来是 enter。这是唯一一个改变旧习惯的地方，提示栏会写清楚；设置里提供“enter = 精确/小数（旧版）”的开关。

### A.3 数据要求

- 每个主题的每个答案都必须有步骤：要么自己有 `steps`，要么有 `explain`，要么明确声明 `no_working = true`（例如直接给出的输入值）。这条由测试检查（`work_coverage` 测试：每个示例题的每个主答案都满足其中一条）。
- 步骤只写本结论新增的推导，用 `uses` 指向依赖。展开时依赖会被折叠成“uses …”行，不会重复。
- 2.x 运动学的 `R:tag(key, deps)` 正好是这个模型的雏形，迁移时直接改写为 deps。

### A.4 和图像联动（P2）

选中一个带 `plot` 信息的答案（点、渐近线、交点、区域），迷你图上把它高亮（加粗、闪一下）。在全屏图里按 enter 选中一个特征点，回到表格时那个答案被选中并展开。

## B. 作图工作台（取代“Function graph”，P1）

### B.1 能放什么

| 对象 | 写法 | 优先级 |
|---|---|---|
| 函数 | `f(x)=x^2-4`、`x^2-4`（自动命名 f, g, h, k…）、带定义域 `x^2-4, 0≤x≤3` 或 `x^2-4 | x>0` | P1 |
| 竖线 / 横线 | `x=2`、`y=-1` | P1 |
| 点 | `A(1,2)`、`(1,2)` | P2 |
| 反函数 | `inverse f` | P2 |
| 参数曲线 | `x=cos(t), y=sin(t)` | P3 |
| 文档函数 | `f11(x)`（读文档里定义的函数，编译不了时提示会慢） | P1（沿用 2.x） |

最多 6 个对象（屏幕和颜色的限制）。每个对象一行，行首有颜色标记，按 enter 编辑，按数字键 1–6 在图上显示/隐藏它。

### B.2 每个函数自己的分析（沿用 2.x，拆成独立的分析器）

渐近线（竖直、水平、斜、曲线）、驻点（极大、极小、驻点拐点）、拐点、截距、空心点、跳跃、端点、不可导点、f′、f″。每一种是一个分析器（`mathx/analysis/*.lua`），可以单独开关、单独测试。

### B.3 问题（选两个对象或一个对象）

| 问题 | 输入 | 输出（每一项都有步骤） | 优先级 |
|---|---|---|---|
| 交点 | 两个对象 | 全部交点（精确，必要时数值），每个交点的坐标 | P1 |
| 两曲线之间的面积 | 两个函数；范围：两个 x 值，或“相邻两交点之间”，或“全部围成的区域” | 面积；在交点处分段、每段的符号表；精确值和小数 | P1 |
| 曲线和 x 轴之间的面积 | 一个函数 + 范围 | 同上（2.x 面积主题已有，统一到这里） | P1 |
| f(x) = k / f(x) ≥ g(x) | 一个或两个函数 + 关系 | 解集（区间） | P2 |
| 切线 / 法线 | 一个函数 + x=a | 切线方程、法线方程，并画出来 | P2 |
| 函数值表 | 一个或多个函数 + 起点、步长 | 表格（每行一个 x） | P2 |
| 平均值 | 一个函数 + 区间 | (1/(b−a))∫f | P3 |
| 复合 f(g(x)) 和定义域 | 两个函数 | 规则和定义域 | P3 |

添加问题的方式：在“问题”区最后一行“+ 添加问题”上按 enter，从列表里选问题类型，再选对象（只列出类型合适的对象），参数输入框随后出现。问题可以删除、可以排序。

**交点的求法：**

1. 先用 CAS：`solve(f(x)=g(x), x) | xmin ≤ x ≤ xmax`（加上两个函数的定义域）。
2. 再做数值检查：在窗口里对 h = f − g 采样，找变号和接近 0 的极小值（切点），用二分/牛顿细化。
3. 两边对照：CAS 漏掉的数值根标为“数值解”，并尝试用 `exact()` 还原精确值；CAS 给出但不在定义域里的根丢掉，并在步骤里说明原因。
4. 每个交点的步骤：方程 → 解 → 代回求 y → （如有）舍去的根和原因。

**面积的求法：** 在区间内找出所有交点并分段，每段判断哪条在上面（取中点的值），分段积分 ∫(上 − 下)，CAS 积分失败时退回 `nInt` 再退回 Lua 数值积分（2.x 的三级回退）。步骤中写出 VCE 要求的形式 `A = ∫_a^b (f(x) − g(x)) dx + …`。

### B.4 看图的功能（全屏查看器）

| 功能 | 按键 | 说明 | 优先级 |
|---|---|---|---|
| 多条曲线、图例 | — | 每条曲线一个颜色，左上角图例 | P1 |
| 当前曲线 | tab | 在曲线之间切换；追踪和跳点只在当前曲线上 | P1 |
| 追踪 | ◀ ▶ | 沿曲线移动，顶部显示 x、y；靠近特征点时吸附并显示精确坐标 | P1 |
| 跳到特征点 | ▲ ▼ | 在当前曲线的特征点（包括交点）之间跳 | P1 |
| 缩放 | + / − | 以光标为中心 | P1 |
| 框选缩放 | z 然后选两个角 | 放大到选定矩形 | P2 |
| 平移 | 8 4 6 2 | 和 2.x 一样 | P1 |
| 适配窗口 | 5（重置）、f（显示全部特征点）、t（三角窗口，刻度为 π/2）、s（等比例） | | P1/P2 |
| 显示/隐藏 | 1–6 曲线，l 标签，a 渐近线，g 网格 | | P1 |
| 区域 | — | 面积问题的区域打上阴影，图例里写面积 | P1 |
| 函数值表 | v | 切到表格页（当前曲线，光标处开始） | P2 |
| 回到答案 | enter（在特征点上） | 回到表格，选中并展开这个答案 | P2 |
| 坐标读数 | — | 吸附到特征点时显示精确值，否则 4 位小数 | P1 |

性能：每条曲线的采样按（窗口、尺寸）缓存；平移时尽量复用已有采样，只补新露出的部分（P2）；陡峭处自适应加密。

### B.5 表格上的布局

```
Functions
  ● f(x) = (x²−3)/(x−2)
  ● g(x) = x + 2
  + add function
Window   x: −6 … 8    y: auto
Graph (enter: full screen)        ← 迷你图，在输入框正下方（2.4 的做法）
Questions
  ∩ f and g: intersections
  ▭ area between f and g, x = 1 … 3
  + add question
Answers
  ▸ f: asymptotes (2) ▸ turning points (2) …      ← 按对象和问题分组
  ▸ f ∩ g (1)
  ▸ area (1)
Graph options                                      ← 2.4 的做法
Working (all)                                      ← 默认折叠
```

窗口用一个区间输入框（接受 `-6,8`、`-6..8`、`[-6,8]`），比 2.x 的两个框少一行；y 窗口同样，可以只给一边（2.4 的规则）。

### B.6 和其他主题的关系

- 2.x 的“面积/体积”主题保留（旋转体、弧长、表面积、带字母常数、“given V=16π”都在那里）；两曲线之间的面积在两边都能做，共用 `mathx/calc/area.lua`。
- “参数（求未知常数）”和“图像变换”可以把结果“发送到作图工作台”（P2），作为新的函数对象。

## C. 向量工作台（取代“Angle between vectors”，P1）

### C.1 对象和写法

每个对象有一个名字（自动给，也可以自己写在前面：`A=(1,2,3)`、`l1: …`、`Π1: …`）。输入时自动识别类型，识别不了就在框下面说明能接受的写法。

| 对象 | 接受的写法 | 优先级 |
|---|---|---|
| 点 | `A(1,2,3)`、`A=(1,2,3)`、`(1,2,3)` | P1 |
| 向量 | `2i−j+3k`、`(2,−1,3)`、`<2,−1,3>`、`[2,−1,3]`、`[[2][−1][3]]`、`AB`（两点之差） | P1 |
| 直线：向量式 | `r = (1,2,3) + t(2,−1,4)`、`(1,2,3) + λ(2,−1,4)`、`i+2j+3k + t(2i−j+4k)` | P1 |
| 直线：参数式 | `x=1+2t, y=2−t, z=3+4t` | P1 |
| 直线：笛卡尔式（对称式） | `(x−1)/2 = (y−2)/(−1) = (z−3)/4`；某个分量为 0 时 `x=1, (y−2)/(−1) = (z−3)/4` | P1 |
| 直线：两点 / 点加方向 | `through A, B`、`through A parallel to u` | P1 |
| 平面：笛卡尔式 | `2x − y + 3z = 7` | P1 |
| 平面：向量（法向）式 | `r·(2,−1,3) = 7`、`r.(2i−j+3k)=7` | P1 |
| 平面：参数式 | `r = (1,0,2) + s(1,1,0) + t(0,1,1)` | P1 |
| 平面：三点 / 点加法向 / 含一条线和一个点 / 含一条线并平行于另一条线 | `through A, B, C`、`through A normal n`、`contains l1 and A`、`contains l1 parallel to l2` | P1/P2 |
| 二维 | 只给两个分量时按平面向量处理（z = 0）；二维直线也可写成 `y = 2x + 1` | P2 |

字母常数：对象里可以有一个字母（例如 `(2, m, 1)`），见 C.4。

### C.2 每个对象自动给出的东西（P1）

选中对象行按 enter 展开，列出它的所有标准形式，每种形式都可以复制：

- **点**：坐标；位置向量。
- **向量**：模长、单位向量、i j k 形式、列向量形式。
- **直线**：向量式 `r = a + λd`；参数式 `x = …, y = …, z = …`；笛卡尔/对称式（分量为 0 时按 VCE 的写法单独写出该坐标）；方向向量；一个点。
- **平面**：笛卡尔式 `ax + by + cz = k`（系数化为互质整数）；向量式 `r·n = k`；参数式 `r = a + λu + μv`；法向量；和三条坐标轴的截距。

选项（在对象行下面或设置里）：

- 参数字母：λ μ t s（直线默认 λ，平面默认 λ, μ；可以改）。
- 变量名：x y z（可以改，例如 x₁ x₂ x₃ 或别的字母）。
- 系数化简：整数（默认）/ 保持原样。

### C.3 问题

先选问题类型，再选对象（只列出类型合适的）。所有距离都是**最短（垂直）距离**。

| 问题 | 对象 | 结果（都有步骤） | 优先级 |
|---|---|---|---|
| 两平面的交线 | Π, Π | 交线的三种形式；平行或重合时说明 | P1 |
| 线面交点 | l, Π | 交点；平行（无交点）或在面内时说明 | P1 |
| 两直线 | l, l | 相交（交点）/ 平行 / 重合 / 异面的判断；夹角 | P1 |
| 点到平面的距离 | A 或原点, Π | 距离、垂足、对称点 | P1 |
| 点到直线的距离 | A 或原点, l | 距离、垂足、对称点 | P1 |
| 两平行平面的距离 | Π, Π | 距离 | P1 |
| 夹角 | 两向量 / 两直线 / 线与面 / 两平面 | 角度（度或弧度）；直线取锐角；线面角用 sin | P1（向量夹角沿用 2.x） |
| 向量运算 | u, v（,w） | 点积、叉积、标量投影和向量投影（vector resolute）、是否平行或垂直、三向量是否线性相关、混合积（平行六面体体积） | P1 |
| 面积 | A, B, C 或 u, v | 三角形面积、平行四边形面积 | P1 |
| 过点作平面或直线 | A + 条件 | 过 A 且垂直于 l 的平面；过 A 且垂直于 Π 的直线；过 A 且平行于 Π 的平面 | P2 |
| 异面直线的距离 | l, l | 最短距离和公垂线的两个端点 | P2 |
| 三平面 | Π, Π, Π | 唯一交点 / 交于一条线 / 无公共点（和联立方程主题共用 `mathx/linsys.lua`） | P2 |
| 分点、中点 | A, B + 比 | 坐标 | P2 |
| 点是否在直线或平面上 | A, l/Π | 是/否和步骤 | P1 |

需要和 VCE Specialist 2023–2027 学习设计逐条核对：向量积、三维平面（向量式、参数式、笛卡尔式）和线面夹角是确定在内的。点到平面的距离、异面直线距离等是否在考试范围内需要确认；不在范围内的放到“更多”分组，默认不显示。

### C.4 带字母的对象：由条件求字母（P1）

2.x 的“由夹角求 m”推广成通用规则：对象里有一个字母时，问题可以带一个条件，例如：

- `l1 ⟂ Π1`、`l1 ∥ Π1`、`l1 in Π1`
- `angle = 60°`
- `distance = 3`
- `l1 and l2 intersect`

工作台把条件写成关于这个字母的方程，用 CAS 解出来，再把字母的值代回所有对象和问题，重新给出结果。条件不够或有多个解时，按 2.x 的方式列出全部解（`param_m`、`param_m2`…）。

### C.5 计算方式

- 向量运算（点积、叉积、模长）在 Lua 里用 Expr AST 组合，**一次** CAS 调用化简整个结果，例如把三个分量放在一个列表 `{…, …, …}` 里求值，而不是每个分量调用一次。这样 CAS 调用次数大约是 2.x 的三分之一。
- 有理数和根式结果保持精确；角度给出精确值（`arccos(…)`）和小数。
- 退化情况统一检查：零向量、平行、重合、点在线上。每种退化都有自己的说明，不会报“无法计算”。

### C.6 表格上的布局

```
Objects
  A  = (1, 2, 3)
  l1 : r = (1,2,3) + λ(2,−1,4)          ▸ forms
  Π1 : 2x − y + 3z = 7                   ▸ forms
  + add object
Questions
  l1 ∩ Π1: intersection point
  distance from O to Π1
  + add question
Answers
  l1 ∩ Π1 = (…)                          enter: working
  d(O, Π1) = 7/√14 = √14/2               enter: working
Options   parameter: λ μ   variables: x y z   angles: degrees
```

### C.7 和联立方程的关系

三平面的交（P2）和 2.x 的“含参数的联立方程”是同一个问题：两个主题都调用 `mathx/linsys.lua`。

## D. 其他配套改动

| 改动 | 说明 | 优先级 |
|---|---|---|
| 缺条件时跳到输入框 | 提示有 `needs`（例如 x0、v0）；在提示上按 enter 跳到第一个要补的框（运动学 2.3 的提示升级） | P1 |
| 输入错误显示在输入框下面 | 解析器给出位置和说明（“第 5 个字符：括号没有闭合”），不再统一放在页面底部的提示里 | P1 |
| 计算中的状态 | 任务在跑时显示“计算中：渐近线…”，可以按 esc 取消 | P1 |
| 题目快照 | menu › “复制题目”：把主题和输入复制成一行文本，可以发给别人或贴到反馈表；粘贴可以还原题目 | P2 |
| 每个主题的帮助 | 在主题里按 ctrl+? 或 menu › 帮助，只显示本主题的写法和例子 | P2 |
| 网站教程用语义按键 | 教程脚本写 `{field:f}`、`{leave}`、`{answer:max1}`，不再写 `{down*9}`（2.4 改行顺序时教程就要跟着改） | P1 |

## 现有主题全部保留

概率（9 种）、SUVAT、运动学、微分方程模型、面积/体积/弧长/表面积、求未知常数、图像变换、含参数联立方程、函数图像（并入作图工作台）、向量夹角（并入向量工作台），功能逐条保留。清单见 [现有功能总结](01-current-features.md)，对照测试见 [迁移计划](05-migration-plan.md)。
