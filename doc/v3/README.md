## 一页摘要

**做什么。** 3.0 在现有 18 个解题器的基础上加三件事：

- 任何答案都能选中后按 enter，在它下面展开它自己的步骤。
- 作图变成可以放多个函数的工作台，能求交点、两曲线之间的面积，全屏图更好用。
- 向量变成三维几何工作台：点、向量、直线、平面，可以用各种写法输入、互相转换，能求交线、交点、距离、夹角，并能由条件求字母。

**为什么要重新设计。** 2.x 的数学和界面混在一起，一切都是字符串，答案不知道自己的步骤，计算会冻结界面，翻译靠匹配英文原句，出了问题在真机上看不到。三件新功能都会撞上这些问题。

**怎么设计。**

1. **分八层，只能向下依赖**，由脚本检查：plat、base、cas、mathx、work、topics、app、ui。
2. **有类型的领域对象**：Expr、Vec3、Line3、Plane3、Fn、Interval。每种对象只有一个解析器和一组格式化函数。
3. **结论图 FactGraph 取代 report**：每个答案是一个 Fact，有依赖和自己的步骤。“展开步骤”就是沿依赖收集步骤。
4. **两种主题**：表单（现有主题）和工作台（作图、向量），共用同一套结论图、行渲染和按键。
5. **计算是任务**：在 coroutine 里分段执行，可以取消，可以先发布一部分结果（先看到图，再出交点）。这要先在真机上验证。
6. **状态分三份**：文档、结果、界面。行由纯函数生成，每行有稳定的 key。
7. **翻译用消息 id 加参数**，不再匹配英文原句。

**怎么调试。**

- 日志环形缓冲、每次 CAS 调用的记录（表达式、结果、耗时）、计时和内存。
- 真机上的调试面板。
- 错误导出：题目快照、问题报告、CAS 录制。
- **在 TI 电脑版软件里录制真 CAS 的结果，带回桌面做回放测试**，解决“mock 不是 TI CAS”。
- 测试分层：单元、CAS 契约、主题金样、2.x 对照、界面（按 key）、性能预算、构建检查、网站、视觉。

**怎么迁移。**

1. 新代码放在 `v3/`，2.x 继续发布，只修 bug。
2. 先做真机验证（M0），再用最简单的主题打通骨架（M1），尽早上线录制回放（M2）。
3. 接着依次做作图工作台（M3）、力学和微积分（M4）、向量工作台（M5）、其余主题（M6）、中文和网站（M7）、发布（M8）。
4. 每个主题用 2.x 的结果做对照测试，确保不丢功能。

## 需要你决定的事

见 [迁移计划 §6](05-migration-plan.md#6-需要你决定的事)。最重要的两条：

1. “平面/线与一个点的最远距离”：点到无限的平面或直线只有最短距离，设计里按**最短（垂直）距离**处理（同时给出垂足和对称点）。如果你指的是别的情况，请说明。
2. 答案上的 enter 从“精确/小数”改为“展开步骤”，精确/小数改用 ◀▶，并在设置里保留旧行为。
